# nutzung-der-plagiatspruefungssoftware-turnitin-similarity-an-der-eth-zuerich

## Main article

Bei Turnitin Similarity handelt es sich um eine Plagiatsprüfsoftware, die Ähnlichkeiten in Texten, einschliesslich Paraphrasierungen, Zitaten und Verweisen erkennt. Die webbasierte Software greift für den Vergleich von Texten auf eine umfangreiche Datenbank mit akademischen – sowohl publizierten als auch unpublizierten – Arbeiten, Büchern, Journals und anderen Quellen zu.

Zugang auf die Software erhalten ausschliesslich Professor:innen und Dozent:innen. Das Erstellen des Accounts erfolgt durch die ETH-Bibliothek und kann über die Webseite Plagiatsprüfung angefordert werden. Dort finden Sie zudem weitere Informationen zur Nutzung der Software sowie Kontaktangaben.

Gemäss Beschluss der Schulleitung wird der Zugang nur denjenigen Personen gewährt, die in der Personensuche der ETH Zürich über die Attribute «Professor / Professorin» oder «Dozent / Dozentin» verfügen. Gleichzeitig vertritt die Schulleitung die Meinung, dass Arbeiten von Studierenden nicht flächendeckend mittels einer Software auf Plagiate geprüft werden sollen.

Informationssicherheit gewährleistet

Der Einführung der Software gingen eine ausführliche Marktanalyse und ein umfangreiches Cloud Assessment voraus. Die Sicherheitsstandards der Software erfüllen die hohen Anforderungen der ETH Zürich im Bereich Informationssicherheit.

Unterstützende Angebote der ETH-Bibliothek

Flankierend bietet die ETH-Bibliothek umfangreiche Informationen und Kurse zur Plagiatsprävention an.
