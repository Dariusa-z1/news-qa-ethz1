A big issue in the last days was the vulnerability called «Heartbleed», which affects, for example, web stores, Internet banking or in general all web services accessed over SLL («https»).

IT Services recommend to all members of ETH to change their passwords affiliated with an ETH account (nethz) using this webtool, if you haven’t changed this week. From that moment on they guarantee that the systems are secure.

More information on the ID-Blog.
