As a member of ETH Zurich, you enjoy access to external pageSciFinder-ncall_made, the latest SciFinder-n interface, which launched on 1 November. Improvements include the more intuitive user interface, better text search capability, parallel use in several browser tabs, analysis and filtering in large hit lists, synthesis planning tools, similarity search function for reactions, add-on workflow tool PatentPak and the display of Markush structures.

Those wishing to use SciFinder-n must register and create a personal account. Existing SciFinder-n Web users can enter their login information and migrate their saved searches and alerts.

SciFinder-n provides comprehensive information about compounds and reactions based on the Chemical Abstracts databases CAplus, CA Registry, CASREACT, CHEMCATS, CHEMLIS and the MEDLINE database.

The ETH Library website contains further information on SciFinder-n and other databases.
